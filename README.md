# Forever Fashion Store

A complete React + Vite fashion e-commerce project with a working browser-local demo mode and the original Express/MongoDB backend preserved for future production integration.

### Fast start
```bash
cd frontend
npm install
npm run dev
```

Customer: `http://localhost:5173`

Admin: `http://localhost:5173/admin`

Admin demo login: `admin@forever.store` / `admin123`

See `START_HERE.md` for the full guide.
